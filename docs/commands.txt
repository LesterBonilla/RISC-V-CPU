Some common commands I run for reference and as a target for automation in the future:

This is run in the base folder of the riscv-arch-test repo to compile the elfs for my
configuration. The build files are located in /work at the base of the repo. 
DEBUG=TRUE generates trace files and trap reports for debugging.

    CONFIG_FILES=config/cores/lester/rv32i/test_config.yaml DEBUG=TRUE make --jobs $(nproc)

These are run to compile the tests and run them. The main painpoint is that they call finish 
at the end, so if you want to use them with the waveform GUI, it runs all the way and asks
for confirmation if you want to close. This means if you want to add the waves, you need to run
it again after it completes the first time. The fix here will be a GUI based test and the non-GUI
regression tests. I plan to make a python script that can call the necessary .do files to do this.

    vsim -c -do sim/archtest-compile.do
    vsim -c -do sim/archtest-run.do

    In vsim terminal:
    do wave.do

This one scans the tests folder and creates a SystemVerilog header file that includes the 
number of tests and an array of tests for iteration in archtest_tb. I want to condense this with
the elf2hex python script to both convert the tests to hex and repopulate the header file if needed.
This will probably be done with make.

    uv run ./scripts/generate_test_list.py ./tests ./testbench/tests.svh

This one converts the elf output from riscv-arch-tests to hex files

    python3 elf2hex.py
